# Planner

A productivity app built to be used by two kinds of users: a human and an AI agent.

## Idea

Most task managers assume one person is clicking the buttons. Planner treats the human and the agent as equal users of the same workspace. Both can create, update, and organize tasks and schedule time, and each can see what the other has done.

## Core parts

- **Tasks** — capture, organize, and track work.
- **Calendar** — plan your schedule, kept in sync with Google Calendar.
- **Agent access** — an AI agent works with the same tasks and calendar as you do.
